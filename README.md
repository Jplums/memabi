# MEMABI (매일메일비서, 매메비)

G메일로 들어온 업무 메일을 Claude가 읽고 **할 일·아침 브리핑·회신 초안**으로 정리해, 바탕화면 오른쪽 위젯으로 보여 주는 Windows 프로그램입니다.

- 위젯: 오늘 할 일, 마감 지남·오늘·이번 주 건수, 검토 대기 초안
- 뷰어: 업무 보드(할 일 추가·마감 바꾸기·완료), 오늘 브리핑, 초안(본문 복사), 선택과 집중
- 할 일의 제목을 누르면 자세한 내용, 출처를 누르면 원래 메일 본문
- **선택과 집중**: 급한 업무를 검색하면 관련 메일을 모아 흐름·해야 할 일을 요약
- 업데이트는 위젯의 **지금 업데이트**를 누를 때만 (Claude 사용량을 아끼려고). 설정에서 1·2시간마다 자동으로 바꿀 수 있습니다.

## 받기

오른쪽 **Releases**에서 가장 위 버전의 `MEMABI_Setup_<버전>.exe`를 받아 실행합니다.
→ https://github.com/Jplums/memabi/releases/latest

## 설치 전에 준비할 것

1. **Windows 10/11**
2. **G메일 계정 + 앱 비밀번호**
   - Google 계정에서 2단계 인증을 켭니다.
   - [앱 비밀번호](https://myaccount.google.com/apppasswords)에서 16자리 비밀번호를 만듭니다.
   - 회사 메일을 쓰면 회사 메일을 이 G메일로 자동 전달해 두세요.
3. **Claude 구독**(Pro·Max·Team) 또는 Claude API 키
   - 설치 마법사에서 Claude Code 설치와 로그인을 함께 합니다.

## 설치

1. `MEMABI_Setup_<버전>.exe`를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
   - 이 창은 회사 인증서로 서명하지 않은 프로그램이라 뜹니다.
2. 처음 실행하면 설정 마법사가 뜹니다. **메일 연결 → Claude 연결 → 업데이트·알림** 순서로 진행합니다.
3. 끝나면 바탕화면 오른쪽 위에 위젯이 뜹니다. **지금 업데이트**를 누르면 첫 메일 정리와 아침 브리핑이 만들어집니다.

## 새 버전

- 새 버전이 나오면 위젯 위쪽과 Windows 알림으로 알려 드립니다.
- **받기**를 눌러 새 설치 파일을 받아 실행하면 됩니다. 내 할 일·설정·메일 연결은 그대로 남습니다.
- 환경설정 › 파일·시작 › **새 버전 확인**으로 직접 확인할 수도 있습니다.

## 내 정보는 어디에

- **메일 앱 비밀번호·API 키**: 이 PC의 Windows 자격 증명 관리자에만 저장됩니다.
- **할 일·메일 기록·초안·브리핑**: `문서\MEMABI` 폴더에 있습니다. 설정에서 바꿀 수 있습니다.
- **메일 읽기 방식**: 메일은 읽기 전용으로 가져오므로 읽음 표시가 바뀌지 않습니다. 메일을 보내거나 지우지 않습니다.
- **Claude에 보내는 내용**: 메일 내용은 정리할 때 내 Claude 계정으로만 보내집니다.

## 지우기

Windows 설정 › 앱 › MEMABI › 제거. 업무 파일(`문서\MEMABI`)과 설정(`%APPDATA%\MEMABI`)은 남으니 필요 없으면 직접 지우세요.
